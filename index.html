About

Siapa Aku?

Aloo! Kenalin, saya A. Aisyah Muthmainnah Binti A. Yushar, biasa dipanggil Aii. Saat ini saya adalah mahasiswa semester 3 Program Studi Teknik Komputer dan Jaringan di Politeknik Negeri Ujung Pandang.

Katanya sih orangnya baik hati, tidak sombong, rajin menabung, dan pastinya fast respon. Saya tertarik pada dunia web development, desain grafis, dan fotografi. Di waktu luang, saya suka menggambar di IbisPaint X, mengedit foto di Lightroom, atau sekadar memasak dan membaca di rumah.

Untuk sekarang, saya masih dalam proses mencari tahu bidang apa yang paling cocok untuk saya. Saya cukup tertarik dengan cybersecurity, tetapi di sisi lain saya juga masih ingin mengeksplorasi web development, desain, networking, dan berbagai bidang teknologi lainnya. Bagi saya, tidak apa-apa belum menentukan satu pilihan sekarang, selama saya masih terus belajar, mencoba hal baru, dan menemukan apa yang benar-benar saya sukai.
